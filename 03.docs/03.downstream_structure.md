# Downstream Analysis Structure

This document summarizes how downstream analyses were organized in the broader development repository. The public package focuses on the controlled-access GWAS workflow and simulated demonstration; downstream directories are described here to make the manuscript-facing analysis structure transparent without distributing controlled-access data or private production infrastructure.

## Analysis Code

`01.analysis/` stores analysis scripts and script-level resources used to generate derived outputs. The main active code is grouped under `01.core_scripts/`, with additional topic-specific pipelines for gene prioritization and related analyses. Scripts in this area produce stable outputs into the corresponding topic folders under `02.results/`.

## Results by Topic

`02.results/` stores generated outputs by analysis topic rather than by manuscript section. Topic folders include:

- `01.exwas`: rare-variant burden and rare/common convergence analyses
- `02.flames`: FLAMES locus-to-gene prioritization outputs
- `03.ldsc_genetic_correlation`: LD Score Regression genetic correlation outputs
- `04.maf_vs_effect`: allele-frequency versus effect-size summaries and figures
- `05.post_bnmf`: post-bNMF cluster interpretation outputs
- `06.snp_clustering`: variant and locus clustering outputs
- `07.allele_freq_beta_scatterplot`: allele-frequency and beta scatterplot source outputs
- `08.cs2ct`: cell-type and tissue score outputs
- `09.overlap_loci`: cross-trait locus overlap outputs
- `10.ukb_leads`: UK Biobank lead-variant tables
- `11.novel_loci`: novelty annotation versus prior literature
- `12.phenotypic_correlation`: phenotypic correlation outputs
- `13.fuji_plot`: locus and cross-trait visualization outputs
- `14.epigenomic_enrichment`: epigenomic enrichment outputs
- `15.open_targets`: Open Targets API and variant-to-gene integration outputs
- `16.AoU_PheWAS`: All of Us PheWAS follow-up outputs
- `17.flames_grch38_rerun_20260609`: GRCh38 FLAMES rerun outputs
- `18.cardiac_novelty_nicholls_lv_20260609`: cardiac novelty update outputs
- `19.overlap_loci_venn`: cross-domain overlap Venn summary outputs

`legacy_outputs/` folders preserve prior output sets for traceability and are not intended to supersede the current publication-ready outputs.

## Manuscript Assembly

`03.manuscript/` reorganizes source outputs into a publication-facing order:

1. Discovery and novelty
2. Shared loci and colocalization
3. Gene prioritization
4. Tissue and cell-type context
5. Downstream phenotypes
6. Clustering and heterogeneity
7. Top-loci examples
8. Main figures
9. Supplementary tables

The manuscript directory does not replace source results. It records which original outputs support each manuscript section, figure, and supplementary table.

## Public Package Boundary

The public `cardiac-adiposity-genomic-atlas` package includes:

- Core sample-QC, variant-QC, phenotype-preparation, and REGENIE GWAS scripts
- Configuration templates and phenotype definitions
- Simulated demonstration data
- Documentation of inputs, method alignment, downstream structure, PheWeb2 browser provenance, and third-party software links

The public package does not include participant-level data, controlled-access UK Biobank or All of Us data, private storage paths, credentials, internal job logs, or derived individual-level results.
