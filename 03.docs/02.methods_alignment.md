# Alignment with manuscript Methods

This public workflow is intentionally narrower than the internal production repositories.

| Manuscript element | Public script |
|---|---|
| Consent, WGS availability, sex concordance, sex chromosome aneuploidy, heterozygosity/missingness and outlier exclusions, WGS batch availability | `02.scripts/01.sample_qc.sh` |
| Autosomal biallelic A/C/G/T SNP restriction and PLINK-compatible QC | `02.scripts/02.variant_qc.sh` |
| Pooled and sex-stratified covariate adjustment; rank-based inverse-normal transformation | `02.scripts/03.prepare_phenotypes.R` |
| REGENIE step 1 whole-genome regression using LD-pruned variants | `02.scripts/04.regenie_step1.sh` |
| REGENIE step 2 quantitative-trait single-variant association testing | `02.scripts/05.regenie_step2.sh` |
| Chromosome concatenation and basic integrity checks | `02.scripts/06.merge_check_results.sh` |

## Important boundaries

The scripts document the principal QC and GWAS workflow but do not reproduce every downstream analysis in the manuscript. Locus definition, cross-trait comparisons, fine-mapping, FLAMES/cS2G/Open Targets integration, rare-variant testing, polygenic-score analyses, PheWAS, bNMF, and browser deployment should be released as separate, focused modules only after removing controlled-access assumptions and validating their inputs.

Manuscript analyses outside this public workflow used additional tools and resources, including Python v3.10.13 and v3.8.13, LD Score Regression, HyPrColoc v0.0.2, FLAMES v1.1.2, CADD v1.6, GTEx v8, PheTK through the All of Us Researcher Workbench, PheWeb2 v2.0.1, SuSiE, cS2G, Open Targets Platform GraphQL API v4, Variant Effect Predictor, EpiMAP 18-state ChromHMM annotations lifted to GRCh38, 1000 Genomes Project Phase 3 European-ancestry LD reference data, and a custom R implementation of BayesNMF.L2EU with half-normal priors and automatic relevance determination weights. Those components are documented here only to clarify scope; they are not required to run the released scripts in this repository.

The sample-QC script consumes already-derived pass/fail indicators rather than directly querying UK Biobank fields. This keeps the public code portable and avoids exposing controlled data structures while preserving the study's exclusion logic.

Before release, compare every threshold here with the final immutable job logs. A manuscript statement such as “predefined quality filters” should not be made more specific in the public README unless those exact filters were used in the final analysis.
