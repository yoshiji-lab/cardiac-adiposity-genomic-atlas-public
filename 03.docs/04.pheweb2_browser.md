# Companion PheWeb2 Browser

The study summary-statistics browser was prepared as a companion PheWeb2 user-interface repository for interactive GWAS and PheWAS visualization. It is separate from the controlled-access GWAS workflow in this package.

## Upstream Project

- Study-specific Imaging PheWeb2 browser: https://github.com/yoshiji-lab/Imaging-PheWeb2.git
- PheWeb2 UI: https://github.com/GaglianoTaliun-Lab/PheWeb2
- PheWeb2 API: https://github.com/GaglianoTaliun-Lab/PheWeb2-API
- Original PheWeb: https://github.com/statgen/pheweb

PheWeb2 supports interactive browsing of GWAS and PheWAS summary-level results, including stratified association results and dynamic locus-level visualizations. The PheWeb2 API handles processed summary-statistics storage and API queries, while the PheWeb2 UI provides the browser interface.

## Local Browser Configuration Represented in the Development Repository

The local companion browser repository was configured as:

- Package name: `Imaging-PheWeb2`
- PheWeb2 UI version: `2.0.1`
- UI framework: Vue 3 with Vite
- Genome build: GRCh38
- Browser title: `Imaging PheWeb`
- Default stratifications: `all.male`, `all.female`
- Release label shown in the UI: `2026-01`

The browser code is intended to display permitted summary-level outputs only. It is not a location for controlled-access participant-level data.
