# Input specifications

## Sample-QC table

A tab-delimited file with one row per participant and these columns:

- `FID`, `IID`
- `consent_ok`
- `wgs_available`
- `sex_concordant`
- `no_sex_chr_aneuploidy`
- `heterozygosity_missingness_ok`
- `not_outlier`
- `wgs_batch_available`

QC indicators must be encoded as 1 (pass) or 0 (fail). Construct these indicators within the approved UK Biobank environment. Do not export or commit participant-level tables.

The study exclusions represented by these fields include withdrawn consent; discordance between self-reported and genetic sex; sex-chromosome aneuploidy; excess heterozygosity or missingness; outlier flags; absent WGS data; and absent WGS batch information.

## Phenotype/covariate table

A tab-delimited file with:

- `FID`, `IID`
- the IDPs listed in `01.config/02.phenotypes.tsv`
- `sex`, encoded consistently as 0/1
- `age`
- `assessment_center`
- `wgs_batch`
- `PC1` through `PC20`
- `BMI`
- `height`

Age, assessment center, BMI, and height should come from the same assessment instance as the selected imaging phenotype. The study prioritized imaging instance 2 and used instance 3 when instance 2 was unavailable.

## Genotypes

One GRCh38 PLINK 2 PGEN/PVAR/PSAM set per chromosome. `PGEN_PATTERN` must contain `{CHR}`, for example:

```text
/controlled/ukb24308_c{CHR}_b0_v1
```

The public repository must not contain WGS data, sample identifiers, or paths exposing controlled project structure.
