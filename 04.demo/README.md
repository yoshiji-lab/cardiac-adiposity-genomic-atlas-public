# Simulated demonstration

This directory contains a simulated demonstration dataset for the released workflow. All records and identifiers are artificial; no UK Biobank, All of Us, or other participant-level data are included.

The included TSV files contain 100 simulated participants with sample-QC indicators, covariates, 20 genetic principal components, and two simulated imaging-derived phenotypes. The dataset is intentionally small enough for rapid local execution while still exercising the core table joins and model terms used by the phenotype-preparation script.

The demo illustrates:

- sample-QC filtering with `02.scripts/01.sample_qc.sh`
- covariate adjustment and rank-based inverse-normalization with `02.scripts/03.prepare_phenotypes.R`

It does not run PLINK 2, REGENIE, or the full genome-wide association analysis.

## Requirements

- Bash
- R with the `data.table` package

The simulated demo is intended as a lightweight public test of the Bash/R portions of the workflow and typically runs in under one minute in a standard Bash/R environment. Full controlled-access analyses should be run in the UK Biobank Research Analysis Platform on DNAnexus, following the project environment used for the study.

## Run

From the repository root:

```bash
bash 04.demo/02.run_demo.sh
```

## Expected outputs

The command writes outputs to `04.demo/output/`:

- `sample_qc/keep.samples.txt`: simulated samples passing the example QC filters
- `phenotypes.processed.tsv`: residualized and inverse-normal transformed simulated phenotypes
- `demo.env`: local demo configuration generated by the script

Successful execution prints the number of simulated samples passing QC and the path to the processed simulated phenotype table.

## Regenerate simulated inputs

The simulated input tables were generated deterministically from `01.generate_simulated_data.R`:

```bash
Rscript 04.demo/01.generate_simulated_data.R
```
